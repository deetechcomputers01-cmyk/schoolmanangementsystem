# ScholarSphere Dashboard Indigo

Use the approved dashboard structure: a 260px white sidebar, 56px white top bar, white content surfaces, and thin #E4E4EC dividers. Use indigo #5B50F5 for primary actions, active navigation, selected tabs, and icon tiles. Use sky blue #3B92E8 only for charts and informational accents. Use #16161D for primary text and #858791 for secondary text. Semantic status colors: forest green (#1B5E20) for Approved/Paid, amber (#FF8F00) for Pending, rose/red (#C24747) for Rejected/Over-Budget. Use Inter typography, compact spacing, and 4px maximum radius for all rectangular elements. Never use dark teal, green branding, gradients, large rounded cards, or dark mode.
